# Titanic-Cleaning
Objective: Clean and prepare the Titanic dataset for analysis.

Tools: Python, Pandas, NumPy, Google Colab.

Methodology -

*Loaded the Titanic CSV dataset.

*Inspected the dataset structure, data types, missing values, and duplicate records.

*Filled missing age values using the median.

*Filled missing boarding-location values using the mode.

*Removed the Cabin column because it contained many missing values.

*Removed duplicate rows.

*Converted columns to appropriate data types.

*Renamed columns for consistency.

*Exported the cleaned dataset as a CSV file.

Deliverables -

Titanic_Data_Cleaning.ipynb

titanic_cleaned.csv

Screenshots documenting the cleaning process.

Outcome

The dataset was cleaned and prepared for further analysis, with the handled missing values and duplicate records checked.
